If you leave a comment on GitHub or are placing any public posting the first
thing that you write needs to be a model disclaimer in the following format:

> This review is by \<model\> by \<provider\>, requested by \<user\>

If you can't discern the current user, you can drop the `, requested by <user>`

An example:

```
> This review is by Claude Opus 5.5 by Antropic, requested John Smith jsmith@test.com
```
